# Amazon to PO

Amazon to PO is a private business automation tool that assists with creating QuickBooks Online purchase orders from Amazon Seller Central order information.

## Overview

The application is designed to:

- Extract order information from Amazon Seller Central.
- Match products using predefined SKU mappings.
- Create purchase orders in QuickBooks Online.
- Reduce manual data entry and improve workflow efficiency.

## Status

This application is currently experimental and intended for internal business use.
